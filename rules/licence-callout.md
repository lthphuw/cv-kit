# Licence callout

When you recommend or load a model, dataset or library, state its licence next to the name. Say so explicitly when it is AGPL, GPL, CC-BY-NC, non-commercial, or a gated custom licence (for example some Meta releases). If the licence was not checked, write `licence UNVERIFIED` rather than guessing. Use the `/cv-kit:cv-model-selection` skill, which reads the plugin's catalog and licence notes.
